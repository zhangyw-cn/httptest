# httptest Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现本机单二进制 HTTP 调试工具：Go 后端代理发出 REST 请求，React 三栏 UI 展示请求/响应/诊断，数据落在 `./.httptest/`。

**Architecture:** 一个进程提供 UI 和 `/api`。`internal/workspace` 负责 `.httptest` 文件；`internal/executor` 做 `{{var}}` 替换并用 `http.Transport`+`httptrace` 出站；`internal/server` 接 API、取消 in-flight 请求、embed 前端。浏览器从不直连目标 URL。

**Tech Stack:** Go 1.22+（标准库 `net/http` ServeMux）、`gopkg.in/yaml.v3`、React 18 + TypeScript + Vite 5、无 Redux、无 SQLite。

## Global Constraints

- 模块路径 `httptest`；二进制名 `httptest`；**内部包不得命名为 `httptest`**。测试里标准库用 `net/http/httptest`。
- 工作区固定为启动时 cwd 下的 `.httptest/`；v1 不提供 `--workspace`。
- 默认监听 `127.0.0.1:1370`；`--listen host:port` 可改为例如 `0.0.0.0:1370`。
- `--open` 可选，启动后尝试打开系统浏览器。
- 变量语法 `{{name}}`；未定义则分类 `invalid`，**不发送**。
- Method 仅：GET、POST、PUT、PATCH、DELETE、HEAD、OPTIONS（落盘大写）。
- 跟随重定向最多 10 次；无关闭跟随开关；无跳过 TLS 开关。
- 默认超时 30s；Body 超过 2MiB 截断并标 `truncated`；未设 UA 时用 `httptest/0.1`。
- `.httptest/.gitignore` 固定内容为 `local/` 与 `history/` 两行。
- v1 不做：Cookie、Basic/Bearer、multipart、HTTP/2、WebSocket、gRPC、SSE、多标签页、登录、云同步、SQLite。

```go
package workspace

import (
	"fmt"
	"path"
	"strings"
)

func CleanRel(rel string) (string, error) {
	rel = strings.TrimSpace(rel)
	rel = strings.ReplaceAll(rel, "\\", "/")
	rel = strings.TrimPrefix(rel, "/")
	if rel == "" || strings.Contains(rel, "..") {
		return "", fmt.Errorf("invalid path %q", rel)
	}
	cleaned := path.Clean(rel)
	if cleaned == "." || strings.HasPrefix(cleaned, "../") || path.IsAbs(cleaned) {
		return "", fmt.Errorf("invalid path %q", rel)
	}
	return cleaned, nil
}
```

`internal/workspace/workspace.go`:

```go
package workspace

import (
	"os"
	"path/filepath"
)

const gitignoreBody = "local/\nhistory/\n"

type Workspace struct {
	dir string
}

func (w *Workspace) Dir() string { return w.dir }

func Init(cwd string) (*Workspace, error) {
	root := filepath.Join(cwd, ".httptest")
	for _, sub := range []string{"collections", "environments", "local", "history"} {
		if err := os.MkdirAll(filepath.Join(root, sub), 0o755); err != nil {
			return nil, err
		}
	}
	gi := filepath.Join(root, ".gitignore")
	if _, err := os.Stat(gi); err != nil {
		if err := os.WriteFile(gi, []byte(gitignoreBody), 0o644); err != nil {
			return nil, err
		}
	}
	return &Workspace{dir: root}, nil
}
```

```go
	for i := 0; i+len(sub) <= len(s); i++ {
```
