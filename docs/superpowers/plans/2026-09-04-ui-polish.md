# UI 配色与控件打磨 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 Primer 色板和壳层上补齐控件状态、收一档密度、对齐空状态，使深浅主题都更干净。

**Architecture:** 全部视觉规则进 `styles.css`（新 token + 四态 + 40/32 密度）。空状态只改 `Sidebar.tsx` / `ResponsePane.tsx` 标记。不改主题模块、快捷键、对话框逻辑、Go API。规格禁止为本功能新增测试文件；回归靠现有 Vitest 与 `go test ./...`。

**Tech Stack:** React 18 + TypeScript + Vite + 手写 CSS；Vitest；Go 1.22 嵌入 `internal/server/ui/`。

## Global Constraints

- 仅改 `web/`（实现后 `cd web && npm run build` 更新 `internal/server/ui/`）；不改 `internal/` 逻辑、`cmd/`。
- 不新增 npm 包、不加载 Web 字体、不加 React Testing Library、不新增测试文件。
- 基础色沿用 2026-09-03：`--bg` `#0d1117`/`#ffffff`、`--surface` `#161b22`/`#f6f8fa`、`--activity` `#010409`/`#f6f8fa`、`--accent` `#1f6feb`/`#0969da` 等，不改数值。
- 不使用 `color-mix`。布局：活动栏常驻、侧栏 220px、双栏 1:1、UrlBar 横跨，均不改。
- 界面中文；协议词保留 Method / Send / Stop / Save。
- README「界面」一节不改。
- 本次不做：换色板、历史当前项高亮、密钥面板重做、空状态插画、把 Send 做得比其它按钮更大。
- 规格：`docs/superpowers/specs/2026-09-04-ui-polish-design.md`。

## File Structure

| 路径 | 职责 |
|------|------|
| `web/src/styles.css` | 新 token、四态、密度、选中条、焦点环、遮罩、空状态排版 |
| `web/src/Sidebar.tsx` | 集合/历史 `empty-state` 标记与文案 |
| `web/src/ResponsePane.tsx` | 响应空状态标记与文案 |
| `internal/server/ui/` | `npm run build` 产物（hashed css/js + index.html） |

不改：`theme.ts`、`ActivityBar.tsx`、`UrlBar.tsx`、`TopBar.tsx`、`Dialog.tsx`（现有 class 足够）、`README.md`。
